PROGRAMACIÓN WEB I - EF TERCER BIMESTRE - TERCERO A MATUTINO

ORDEN DE EJECUCIÓN

OPCIÓN RÁPIDA
   - Ejecute abrir-productos-angular.bat con doble clic.
   - Este archivo inicia ProductosSOAP, MovimientosREST, Angular y abre http://localhost:4200.
   - Para importar pruebas REST, ejecute Postman/abrir-productos-postman.bat o importe el JSON en Postman.

1. SQL SERVER
   - Ejecute SQL/EF3_Productos_Movimientos.sql en SQL Server Management Studio.
   - Si su instancia no es localhost\SQLEXPRESS, ajuste DefaultConnection en los appsettings.json.

2. PRODUCTOS SOAP
   - Abra ProductosSOAP/ProductosSOAP.csproj en Visual Studio.
   - Ejecute el perfil HTTP.
   - Servicio: http://localhost:5163/ProductoService.svc
   - WSDL: http://localhost:5163/ProductoService.svc?wsdl

3. MOVIMIENTOS REST
   - Abra MovimientosREST/MovimientosREST.csproj en Visual Studio.
   - Ejecute el perfil HTTP.
   - URL base: http://localhost:5265

4. PRODUCTOS ANGULAR
   - Abra una terminal en productos-angular.
   - Ejecute: npm install
   - Ejecute: ng serve
   - URL: http://localhost:4200
   - También puede ejecutar abrir-productos-angular.bat con doble clic.
   - Si solo desea abrir Angular, ejecute productos-angular/abrir-angular.bat.
   - Para que aparezcan productos, SQL Server, ProductosSOAP y MovimientosREST deben estar ejecutándose.

5. Las pruebas REST deben realizarse con Postman.
   - Importe el archivo Postman/POSTMAN_MovimientosREST.postman_collection.json en Postman.
   - También puede ejecutar Postman/abrir-productos-postman.bat para abrir el archivo.
   Endpoints existentes para pruebas manuales:
   GET  http://localhost:5265/api/MovimientoInventario
   GET  http://localhost:5265/api/MovimientoInventario/1
   GET  http://localhost:5265/api/MovimientoInventario/producto/1
   POST http://localhost:5265/api/MovimientoInventario

ESTADO DEL PROYECTO
- ProductosSOAP se entrega funcional.
- MovimientosREST se entrega funcional con validaciones e integración SOAP.
- Angular se entrega funcional consumiendo REST y SOAP.
